## 开发理念

- **保持好奇**：从真实问题出发学习，而不是只收集技术名词
- **先做出来**：用可以运行的最小版本验证想法，再持续完善细节
- **重视沉淀**：让代码、文档和复盘共同成为项目的一部分
- **长期迭代**：接受不完美的开始，但要求每一次提交都比之前更清晰
